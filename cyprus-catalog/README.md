# Каталог полезных компаний и руководств по Кипру — рабочая папка проекта

- `docs/01-inventory.md` — что уже есть в Google Drive: категории, полнота, расхождения.
- `docs/02-mvp-plan.md` — позиционирование, монетизация, MVP, стек, структура данных, план запуска.
- `data/companies_seed.csv` — 89 компаний из существующих таблиц. Только публичные данные, все с `publish_ready=no` до проверки.
- `scripts/build_seed.py` — пересборка seed из выгрузки таблицы «Коллаборации — контакты и ответы» (.xlsx).

Статусы переговоров с компаниями в репозиторий не кладутся (`partners_internal.csv` в `.gitignore`).
