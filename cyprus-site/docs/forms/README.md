# Форма «Добавить компанию»: заявки на почту

Страница `/add-company/` отправляет заявку (JSON) на адрес из переменной окружения `PUBLIC_FORM_ENDPOINT`.
Пока переменная не задана, форма работает в тестовом режиме: проверяет поля и честно сообщает, что заявка не отправлена.

Приёмник — небольшой скрипт Google Apps Script (`add-company.gs`):
- **каждая заявка приходит письмом** в Gmail того аккаунта, от имени которого скрипт развёрнут.
  Адрес нигде не прописан, на сайте его не видно. Кнопка «Ответить» в письме сразу адресована заявителю,
  если тот оставил email;
- если скрипт создан внутри Google-таблицы, заявка дополнительно записывается строкой на лист «Заявки компаний».

## Установка (около 5 минут, бесплатно)

**Только почта:**
1. Откройте https://script.google.com под тем аккаунтом, куда должны приходить письма → «Новый проект».
2. Удалите заготовку, вставьте код из `docs/forms/add-company.gs`, сохраните.
3. «Развернуть» → «Новое развёртывание» → тип «Веб-приложение»:
   - «Выполнять от имени»: **меня**;
   - «У кого есть доступ»: **все** (иначе сайт не сможет отправить заявку; читать вашу почту это не позволяет).
4. Разрешите скрипту отправлять письма от вашего имени (Google покажет предупреждение для непроверенного
   приложения: «Дополнительные настройки» → «Перейти»). Скопируйте URL веб-приложения (заканчивается на `/exec`).
5. Укажите его при сборке сайта: `PUBLIC_FORM_ENDPOINT=https://script.google.com/macros/s/.../exec`.

**Почта + таблица:** то же самое, но в шаге 1 создайте Google-таблицу и откройте «Расширения → Apps Script».

## Ограничения
- Gmail-аккаунт может отправить скриптом около 100 писем в сутки. Для заявок этого достаточно.
- Запрос уходит в режиме `no-cors`, поэтому сайт не видит ответ скрипта. Если скрипт перестанет работать,
  человек всё равно увидит «Спасибо». После подключения отправьте тестовую заявку и периодически проверяйте почту.
- Защита от спама — скрытое поле-ловушка. Если спама станет много, добавить капчу (например, Cloudflare Turnstile).
- Контакты заявителя — персональные данные. Перед запуском нужна страница `/privacy` (WEB-024).
