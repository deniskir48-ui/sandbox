# Форма «Добавить компанию»: подключение приёма заявок

Страница `/add-company/` отправляет заявку POST-запросом (JSON) на адрес из переменной окружения
`PUBLIC_FORM_ENDPOINT`. Пока переменная не задана, форма работает в тестовом режиме: проверяет поля
и честно сообщает, что заявка не отправлена.

## Вариант по умолчанию: Google-таблица + Apps Script (бесплатно, ~5 минут)

1. Создайте Google-таблицу, например «Сайт Кипра — заявки компаний».
2. В таблице: **Расширения → Apps Script**. Удалите заготовку и вставьте код из `docs/forms/add-company.gs`. Сохраните.
3. **Развернуть → Новое развёртывание → тип «Веб-приложение»**:
   - «Выполнять от имени»: **меня**;
   - «У кого есть доступ»: **все** (иначе сайт не сможет отправить заявку).
4. Подтвердите доступ к таблице. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).
5. Задайте его при сборке сайта: `PUBLIC_FORM_ENDPOINT=https://script.google.com/macros/s/.../exec`
   (в настройках хостинга — Environment variables).

Заявки появятся на листе «Заявки компаний» со статусом «Новая». Публикация на сайте — только после
проверки, как и для остальных записей (шаблон `docs/templates/company.yaml`).

## Ограничения
- Запрос уходит в режиме `no-cors`, поэтому сайт не видит ответ скрипта. Если скрипт сломан,
  пользователь всё равно увидит «Спасибо». Раз в неделю проверяйте, что заявки приходят.
- Защита от спама — скрытое поле-ловушка. Если спама станет много, добавить капчу (например, Cloudflare Turnstile).
- Контакты заявителя — персональные данные. Перед запуском добавить страницу `/privacy` (WEB-024).
