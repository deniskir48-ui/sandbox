# Пошаговая инструкция для новичка

Программирование знать не нужно: просто повторяйте шаги по порядку. Первый запуск займёт
примерно 30–40 минут, потом ролик делается одной командой.

---

## Шаг 1. Установите программы (один раз)

### Windows
1. **Python**: скачайте с https://www.python.org/downloads/ и запустите установщик.
   ⚠️ На первом экране поставьте галочку **«Add python.exe to PATH»**.
2. **ffmpeg** (программа для монтажа): нажмите Пуск, найдите **«Терминал»** (или «PowerShell»),
   откройте его, вставьте команду и нажмите Enter:
   ```
   winget install Gyan.FFmpeg
   ```
3. Закройте терминал и откройте заново, чтобы он «увидел» новые программы.

### Mac
1. Откройте программу **«Терминал»** (Cmd + пробел → введите «Терминал»).
2. Установите Homebrew: вставьте команду с сайта https://brew.sh и нажмите Enter.
3. Потом вставьте:
   ```
   brew install python ffmpeg
   ```

## Шаг 2. Скачайте код

1. Откройте https://github.com/deniskir48-ui/sandbox
2. Зелёная кнопка **Code** → **Download ZIP**.
3. Распакуйте архив, например на Рабочий стол. Получится папка `sandbox-main`.

---

## Шаг 3. Откройте терминал в этой папке

- **Windows**: откройте папку в Проводнике, нажмите правой кнопкой на пустом месте →
  **«Открыть в Терминале»**.
- **Mac**: в Терминале наберите `cd ` (с пробелом), перетащите папку в окно Терминала, нажмите Enter.

---

## Шаг 4. Установите систему (один раз)

Вставляйте команды по одной и нажимайте Enter после каждой.

**Windows:**
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**Mac:**
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Если в начале строки терминала появилось `(.venv)`, всё получилось.

---

## Шаг 5. Получите два ключа

1. **Ключ Claude** (мозг агентов, платно, оплата за использование):
   https://platform.claude.com → зарегистрируйтесь → пополните баланс на $5–10 →
   **API Keys** → **Create Key** → скопируйте ключ (начинается с `sk-ant-`).
2. **Ключ Pixabay** (бесплатные видео для фона): зарегистрируйтесь на https://pixabay.com, затем откройте
   https://pixabay.com/api/docs/ — в разделе **Parameters** будет строка `key` с вашим ключом.
   (Вместо Pixabay подойдёт ключ Pexels: https://www.pexels.com/api/ →
   зарегистрируйтесь → скопируйте ключ; впишите его в строку PEXELS_API_KEY.)

---

## Шаг 6. Впишите ключи

1. В папке найдите файл `.env.example`, сделайте его копию и назовите `.env`.
   (На Mac файлы с точкой скрыты, показать их можно сочетанием Cmd + Shift + .)
2. Откройте `.env` Блокнотом или TextEdit и вставьте ключи после знака `=`:
   ```
   ANTHROPIC_API_KEY=sk-ant-ваш-ключ
   PIXABAY_API_KEY=ваш-ключ-pixabay
   ```
3. Сохраните.
4. Сделайте копию файла `config.example.yaml` и назовите её `config.yaml`.
   Там уже всё настроено под англоязычный канал про спорт, питание и ЗОЖ.

---

## Шаг 7. Сделайте первый ролик 🎬

```
python -m video_agents run
```

Подождите 3–5 минут. В терминале будет видно, как работают агенты: придумывают тему,
пишут сценарий, редактор его проверяет, потом идёт монтаж.

Готовое видео лежит в папке `workspace/jobs/<дата-и-номер>/final.mp4`. Откройте и посмотрите.

Другие полезные команды:
| Команда | Что делает |
|---|---|
| `python -m video_agents run -n 3` | сделать 3 ролика подряд |
| `python -m video_agents run --topic "Why you should walk 10000 steps"` | ролик на вашу тему |
| `python -m video_agents ideas` | показать идеи, ничего не снимая |
| `python -m video_agents list` | список всех роликов |

> При каждом новом открытии терминала сначала зайдите в папку (шаг 3) и включите окружение:
> `.venv\Scripts\activate` (Windows) или `source .venv/bin/activate` (Mac).

---

## Шаг 8. Публикация (когда ролики понравятся)

Каждую платформу нужно подключить один раз: получить доступ к её API. Это самый
муторный шаг, инструкции для каждой площадки есть в `README.md`, раздел «Подключение платформ».
Можно начать с одной площадки, например YouTube.

После подключения ролик публикуется так:
```
python -m video_agents publish <номер-ролика>
```
Номер ролика показывает команда `list`.
